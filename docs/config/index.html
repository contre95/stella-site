Configuration

Stella reads config.yaml from the working directory, or from the path in STELLA_CONFIG_PATH. This is the full example config (config.example.yaml in the repo), with every setting at its default:

  • auth is explained in Users & login.
  • mcp is explained in MCP server.
  • review tunes the scheduler, see Reviewing.
  • server.bodyLimit is the largest request body in bytes (10 MiB by default), which caps the size of uploaded media and imported archives.
