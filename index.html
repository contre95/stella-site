Stella

Self-hosted spaced repetition, with Mnemosyne's SM2 at its core

Read the docs Try the demo GitHub

Spaced repetition, on your own server

Everything you need to learn and keep what you learned.

SM2 scheduling

A faithful Go port of Mnemosyne's SM2 algorithm decides what you review and when.

Rich cards

Markdown with colors, furigana, text-to-speech, KaTeX math, images and audio.

MCP server

Let Claude or any MCP client create and organize your decks for you.

Single or multi-user

No login for a lone self-hoster, or OIDC login so friends and family get their own decks.

Import & export

Move decks and groups around as zip archives, review history included.

Self-hosted

One container, a SQLite database and a YAML config. Your cards stay yours.
